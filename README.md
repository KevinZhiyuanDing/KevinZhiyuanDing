## Hi there 👋 I'm Kevin Ding :)

I am a Computer Engineering student at UBC (BASc, 2027/28). I work mostly on machine learning, operating systems, and embedded firmware.

Right now I'm:

- A software engineer co-op at OSI Maritime Systems.
- An ML research assistant in Alexandra Fedorova's lab at UBC, working on machine learning for memory prefetching.
- Telemetry lead for UBC Supermileage, writing the firmware that collect and streams data for our competition cars.

### Some Cool Projects I Did

- **[Socratic AI](https://socratic-ai-gamma.vercel.app)** -- An AI tutoring platform that guides students using the Socratic method.
- **[CNN from Scratch](https://github.com/KevinZhiyuanDing/CNN-from-scratch)** -- A convolutional neural network from scratch using NumPy (no frameworks), achieving 98% test accuracy on MNIST.
- **[Vehicle Telemetry (UBC Supermileage)](https://github.com/supermileage/telemetry-firmware)** -- A real-time vehicle telemetry system streaming sensor, ECU, and GPS data to a live Grafana dashboard over LTE.
- **[CAN bridge (UBC Supermileage)](https://github.com/supermileage/Speeduino-CAN-Coprocessor)** -- An STM32-based CAN bridge that connects a Speeduino ECU to a vehicle CAN network to relay engine data as real-time telemetry.
- **[RISC-V Processor](https://github.com/KevinZhiyuanDing/RISC-V-Processor)** -- A 16-bit, 5-stage pipelined CPU in SystemVerilog, synthesized onto a DE1-SoC FPGA.
- **[LLM Fine-Tuning for Spam Detection](https://github.com/KevinZhiyuanDing/CPEN455-Project-2025W1)** -- A fine-tuned LLM using Bayesian inverse inference on token log-probs. Acheived 96%+ test accuracy, 3rd of 107 teams in the 2025 CPEN 455 Kaggle competition.
